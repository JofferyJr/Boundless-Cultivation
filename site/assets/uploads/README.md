# Boundless — General Image Upload Folder

Letakkan semua gambar/aset sementara di folder ini.

Contoh:
- Character / Face
- Traits
- Bakat
- Bloodline
- Physique
- Items
- Weapons
- Armour
- Bestiary
- NPC
- Maps
- Buildings
- UI
- Events
- Aset lain

Selepas aset siap, pindahkan atau salin ke folder kategori rasmi yang sesuai.

Folder ini wujud sebagai ruang upload umum dan bukan folder runtime rasmi untuk semua aset.
