# General Image Upload Slot

Gunakan folder `site/assets/uploads/` sebagai tempat sementara untuk memuat naik **semua jenis gambar** yang akan digunakan atau dipindahkan ke lokasi aset rasmi Boundless.

Contoh:
- Character / Face
- Traits
- Talents / Bakat
- Bloodline
- Physique
- Items
- Weapons
- Armour
- Accessories
- Bestiary
- Maps
- NPC
- Buildings
- UI
- Event
- Other game assets

Jangan anggap fail di sini sebagai lokasi runtime rasmi. Selepas aset siap, ia boleh dipindahkan ke folder kategori yang sesuai tanpa perlu mencari fail melalui seluruh repository.
