# Instant Realm Slot — 洞天福地

This folder represents **one single map slot** combining three related cultivation-space concepts:

- **Instant Realm / Grotto-Heaven Manifestation (洞天福地):** a private paradise dimension for cultivation, hidden farming, and shelter.
- **Absolute Domain / Law Domain (法则领域):** the owner's spiritual domain where chosen elements or laws dominate.
- **Boundary Creation / Mirror World (结界术):** a folded, isolated pocket space shielded from outside observation or interference.

## Slot rule

- Slot count: **1**
- These three concepts are features of the same slot, not separate slots.
- Suggested visual assets belong in this folder: floating mountains, a spiritual lake, mist, a secluded pavilion, and a subtle spatial boundary.

This is an asset folder definition only; the game UI and runtime mechanics must be connected separately before the slot appears or functions in-game.
