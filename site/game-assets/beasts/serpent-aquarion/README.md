# Serpent Aquarion

Evolusi pertama bagi **Bluewater Serpent** dalam konsep evolusi Haiwan Roh Boundless.

## Reka bentuk
- Masih jelas menyerupai ular air dan mengekalkan garis keturunan Serpent Air.
- Bentuk peralihan: sirip cyan lebih berkembang, tunas tanduk kecil, dan kemungkinan tunas anggota mengikut laluan evolusi.
- Jangan reka bentuk sebagai Wyrm atau naga.
- Kekalkan identiti visual Bluewater Serpent asal: sisik biru, bahagian perut putih keperakan, dan ciri akuatik.

## Fail imej
Letakkan imej sebenar dalam folder ini menggunakan nama fail berikut:
- `egg.webp` — telur (jika diperlukan untuk kitaran spesies)
- `baby.webp` — bentuk bayi/evolusi awal
- `adolescent.webp` — bentuk remaja Serpent Aquarion
- `adult.webp` — bentuk dewasa untuk laluan ini, jika ditetapkan

**Nota:** Folder ini menyediakan tempat untuk aset. Fail imej belum ditambah. Nama dan laluan evolusi ini ialah konsep reka bentuk; sambungan sistem evolusi dalam permainan belum dibuat.
