# Azure Tide Serpent

Bentuk evolusi lanjutan Bluewater Serpent melalui Serpent Aquarion. Ini ialah penghujung laluan evolusi yang dipersetujui setakat ini.

## Reka bentuk
- Spesies Serpent Air yang berbeza dalam garis keturunan yang sama.
- Badan serpentin yang panjang dan fleksibel; bukan Wyrm atau naga.
- Sisik biru-perak, tanduk akuatik lebih matang, sirip cyan berlapis, dan corak tenaga menyerupai arus pasang surut.
- Kekalkan ciri visual dan identiti yang berasal daripada Bluewater Serpent asal.

## Fail imej
Letakkan imej sebenar dalam folder ini menggunakan nama fail berikut:
- `egg.webp` — telur (jika diperlukan untuk kitaran spesies)
- `baby.webp` — peringkat bayi (jika spesies ini boleh bermula pada peringkat bayi)
- `adolescent.webp` — bentuk remaja/evolusi
- `adult.webp` — bentuk dewasa Azure Tide Serpent

**Nota:** Folder ini menyediakan tempat untuk aset. Fail imej belum ditambah. Laluan evolusi dan event belum disambungkan kepada sistem permainan.
